# homebrew-browser-schedule

Homebrew cask tap for [BrowserSchedule](https://github.com/radiosilence/browser-schedule).

## Install

```sh
brew install radiosilence/browser-schedule/browser-schedule
```

Or add the tap first:

```sh
brew tap radiosilence/browser-schedule
brew install browser-schedule
```

## Update

```sh
brew upgrade browser-schedule
```

## Uninstall

```sh
brew uninstall browser-schedule
brew untap radiosilence/browser-schedule
```

## Notes

- Requires macOS Sonoma or later
- The cask automatically removes the macOS quarantine attribute (`xattr -cr`) after installation, as the app is not notarized
